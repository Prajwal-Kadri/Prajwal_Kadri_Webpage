# Prajwal Kadri — Professional Portfolio

This repository includes a static, GitHub Pages-ready version of the portfolio in [`docs/`](docs/).

## Publish with GitHub Pages

1. Create a GitHub repository and push this folder to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and the `/docs` folder, then save.

GitHub will publish the portfolio at:

`https://<your-github-username>.github.io/<repository-name>/`

The static site requires no server, payment plan, or build step.
